fecha, y **no se actualizan**: su valor está precisamente en no cambiar, porque son la evidencia que
respalda decisiones ya tomadas.

> cambiaron (mocks que ya no existen, la escritura al PLC que pasó de cerrada a abierta, pendientes
> ya resueltos). Para el estado de hoy: [`../PENDIENTES.md`](../PENDIENTES.md) y
> [`../../README.md`](../../README.md).
